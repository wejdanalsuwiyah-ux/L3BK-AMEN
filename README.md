# لعبك آمن 🛡️

منصة بحث عن الألعاب تعطيك تقرير فحص أمني لأي لعبة قبل ما تلعبها: التواصل مع الغرباء، المشتريات، الخصوصية، حماية الحساب، الاحتيال، الرقابة الأبوية، ومصدر التحميل.

مشروع ضمن برنامج **مبدعون** (برنامج بنك الجزيرة لدعم الابتكار) — النسخة الخامسة، الأمن السيبراني.
